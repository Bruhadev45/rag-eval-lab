# Legal demo: held-out retrieval ablation

Fictional data, not law and not legal advice. Generated by
`python -m rageval.legal_demo.heldout`; edits here are overwritten.
Each variant ran on the 19 test queries (12 with evidence,
from 7 cases). The settings were fixed on dev before test was run:
depth 3, context 2, the frozen dev selection `sha256:a38309eefe854f5046713659d44ea5b6d961e9dfb44e605dacae8ee53cc59ae1`.

Lexical only: no embedding, cross-encoder or language model was run, so there is
no learned-dense row. Seven test cases cannot separate small differences; these
numbers check the variants' code paths on fictional data, not retrieval quality.

- References: `sha256:18348fc818da971d45edc8a428fca6427ce7ee5423eba60f6ce9cc8d0193d1fd` (minirag `9c9d5d8`)
- Uncertainty: by case (paraphrases of one case are averaged first); rageval.stats paired bootstrap, 10000 case resamples, seed 70
